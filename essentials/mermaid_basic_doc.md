| Syntax | Shape | Typical use |
| --- | --- | --- |
| `((text))` | Circle/oval | Start / End |
| `(text)` | Rounded rectangle | Softer process step |
| `[text]` | Rectangle | Standard process |
| `{text}` | Diamond | Decision |
| `[/text/]` or `[\text\]` | Parallelogram | Input / Output |
| `[[text]]` | Subroutine (double-bordered rectangle) | Predefined process |
